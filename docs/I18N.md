# 国际化体系 · Internationalization

## 1. 支持语言

| 代码 | 语言 | 文件 |
|------|------|------|
| `zh-CN` | 简体中文 | `src/locales/zh-CN.json` |
| `zh-Hant` | 繁體中文 | `src/locales/zh-Hant.json` |
| `en` | English | `src/locales/en.json` |
| `ja` | 日本語 | `src/locales/ja.json` |
| `fr` | Français | `src/locales/fr.json` |
| `es` | Español | `src/locales/es.json` |

每种语言是一个独立 JSON 文件，使用扁平 key + `{placeholder}` 变量。`src/locales/*.json` 是**唯一文案来源**。

## 2. 生成离线语言包

浏览器在 `file://` 下不能 `fetch` JSON，微信小程序也使用 CommonJS，因此构建脚本把 JSON 嵌入为一个 JS bundle：

```bash
npm run build:locales
# 输出 src/ui/locales-data.js（自动生成，勿手改）
```

`scripts/build-locales.js` 会检查：

- 6 个语言包 key 完全一致；
- 每个 key 的占位符集合一致；
- JSON 可解析；
- 生成 `locales-data.js`。

`test/i18n.test.js` 会再次比较 JSON 与生成 bundle，防止忘记重新生成。

## 3. 全局翻译工具

`src/ui/i18n.js` 提供：

```js
const { t, setLang, getLang, languages, explain } = window.Sudoku.i18n;

t('play.ready', { difficulty: 'Easy', clues: 30 });
setLang('ja');            // 实时切换，不刷新
getLang();                // 'ja'
languages();              // 六项 { code, label }
explain(step);            // 结构化技巧解释
```

语言代码别名自动归一化：

- `zh` / `zh-CN` / `zh-Hans` → `zh-CN`
- `zh-TW` / `zh-HK` / `zh-Hant` → `zh-Hant`
- `en-*`、`ja-*`、`fr-*`、`es-*` → 对应语言

选择结果保存到本地存储：

- Web/Windows/Android/iOS：`localStorage['sudoku.lang']`
- 微信：`wx.setStorageSync('sudoku.lang')`

刷新/重启后恢复上次语言。

## 4. 语言选择组件

- Web/Electron/Android/iOS：顶栏 `<select id="langSelect">`，6 个选项，`change` 后 `i18n.setLang()`。
- 微信小程序：原生 `<picker mode="selector">`，同样 6 个选项。
- 下拉菜单使用各语言的本地名称（简体中文、繁體中文、English、日本語、Français、Español）。

切换语言会立即重绘：

- 导航、按钮、标题、占位符、aria-label
- 游戏状态、计时、提示、胜利用语
- 构造器四态
- 求解器技巧名、步骤说明、统计、自动播放
- 回放操作描述、统计面板、主题名称
- 日期格式（`Intl` locale）

## 5. 技巧说明的本地化

技巧实现不包含任何用户文案。每个步骤只保存：

```js
{
  technique: 'hiddenSingle',
  explainKey: 'explain.hiddenSingle',
  explainVars: {
    digit: 4,
    unit: { kind: 'unit', type: 'col', index: 3 },
    cell: { kind: 'cell', index: 30 }
  }
}
```

`i18n.explain(step)` 负责：

1. 将 cell/units/digits/candidates/chain 等语言中立引用格式化为当前语言；
2. 套用 `src/locales/<lang>.json` 中的 `explain.*` 模板；
3. 替换占位符。

因此：

- 19 个技巧的说明全部来自语言包；
- 新增一种语言不需要改求解器；
- 列表分隔符、行列宫名称也按语言包本地化；
- 算法文件 `src/engine/techniques/*.js` 不再含中文/英文解释文本。

## 6. 新语言接入流程

1. 复制 `src/locales/en.json` 为新语言文件；
2. 翻译所有值，保留 `{placeholder}`；
3. 在 `src/ui/i18n.js` 的 `LANGUAGES` / `INTL_LOCALES` 注册；
4. 运行 `npm run build:locales`；
5. 运行 `npm test`；
6. 在 Web 语言下拉中验证所有页面；
7. 微信仍需使用同一 bundle（同步脚本会复制到 `shared/ui/`）。

当前任务固定 6 种语言，新增语言不影响已有代码结构。

## 7. 防漏译机制

- `test/i18n.test.js`：
  - 6 个 JSON 与生成的 bundle 完全一致；
  - key 集合与占位符集合一致；
  - 19 个技巧在每个语言均有名称和说明；
  - 所有 `explain.*` key 在 6 种语言都存在；
  - `index.html` 中所有 `data-i18n*` key 均存在；
  - Web/小程序 UI 源文件不含硬编码 CJK 文案。
- `test/engine.test.js` / `test/techniques.test.js`：
  - 每个真实步骤在 6 种语言下都能生成非空说明；
  - 不允许残留 `{placeholder}` 或 `undefined`。
- 手工验收：语言下拉逐项切换，核对游戏、构造器、求解器、回放、统计、主题和弹窗。

## 8. 平台一致性

| 平台 | 文案来源 | 切换方式 |
|------|----------|----------|
| Web | `src/locales/*.json` → bundle | 顶栏下拉 |
| Windows | 同一 Web 资源 | 顶栏下拉 |
| Android | 同一 Web 资源 | 顶栏下拉 |
| iOS | 同一 Web 资源 | 顶栏下拉 |
| 微信小程序 | `shared/ui/locales-data.js` | 原生 picker |

五种语言方案在同一份语言包上工作，不存在平台自建翻译表。

## 7. OCR 文案（V12）

拍照导入新增 24 个 `ocr.*` 键，六种语言全部提供：

- 入口/标题/说明：`ocr.open`、`ocr.title`、`ocr.desc`、`ocr.offline`
- 拍摄引导：`ocr.guide`、`ocr.guide.align`、`ocr.guide.light`、`ocr.guide.focus`
- 操作：`ocr.camera`、`ocr.album`、`ocr.capture`、`ocr.retry`
- 进度：`ocr.loading`、`ocr.recognizing`、`ocr.previewEmpty`
- 失败原因：`ocr.failed`、`ocr.failed.noGrid`、`ocr.failed.unclear`、`ocr.failed.invalid`、`ocr.failed.unsolvable`、`ocr.failed.engine`、`ocr.failed.noCamera`
- 成功提示：`ocr.success`、`ocr.successVerify`

所有键通过 `src/locales/*.json` 的键/占位符一致性测试，UI 与微信页面均无硬编码 OCR 文案。
